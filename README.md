# T4 vs *E. coli* — виртуальная лаборатория

Браузерное приложение для проектной работы ученика 4-го класса «Как вирусы заражают бактерии».
Техническое задание — [PLAN.md](PLAN.md). Программой на защите пользуется сам ученик, поэтому главный
модуль — «Микроскоп» с простыми словами и пояснениями; научная модель работает «под капотом»,
а все параметры доступны во вкладке «Для взрослых».

## Запуск

```bash
npm install
npm run dev        # режим разработки: http://localhost:5173
npm run build      # проверка типов + сборка в один файл dist/index.html
npm run preview    # посмотреть собранную версию
npm test           # модульные тесты и автотесты «Проверки модели»
```

Сборка — **один файл `dist/index.html`** (~900 КБ), внутри которого весь код и стили.
Его можно скопировать на флешку или другой компьютер и открыть двойным щелчком
в Chrome, Edge или Firefox — без сервера и без интернета. Тот же файл можно выложить
на любой статический хостинг (GitHub Pages, Netlify и т. п.).

Почему один файл: браузеры не загружают отдельные JS-модули со страницы, открытой
с диска (`file://`), — при обычной многофайловой сборке получилась бы пустая страница.

## Модель колбы (модуль 1)

Переменные: S — чувствительные клетки, I(a) — заражённые по когортам «возраста развития» a,
R — устойчивые мутанты OmpC⁻, P — свободные фаги (дикий тип и r-мутанты отдельно), N — субстрат.

* Рост S и R по Моно с потреблением субстрата; у R плата за устойчивость.
* Адсорбция с константой k на чувствительные, заражённые и (с долей α_R) устойчивые клетки.
  Число заражённых клеток считается как S·(1 − e^(−m)), где m — среднее число попаданий на клетку.
* Латентный период — фиксированная задержка: клетка лизируется, когда возраст её когорты достигает L
  (нормальный разброс σ_L). Зрелые частицы накапливаются линейно после эклипса E.
* Торможение лизиса (только дикий тип): повторная адсорбция после t_SIE переводит клетку в заторможенное
  состояние; торможение срывается, если за окно τ_LI не было новых адсорбций (вероятность срыва
  e^(−kPτ_LI)/τ_LI в минуту), и не длится дольше T_LI. Урожай растёт до B_max.
* Физиология хозяина: скорость развития фага и урожай падают в голодающих клетках.
* Мутации S → R при делениях, r-мутации у потомства дикого типа.
* Гибридная стохастика: события с ожидаемым числом за шаг меньше порога (1000) разыгрываются
  по Пуассону и биному, популяции меньше порога хранятся целыми числами.
* Инокулят выращивается из 1000 клеток с мутациями, поэтому начальное число устойчивых мутантов
  подчиняется распределению Луриа — Дельбрюка.

Измерения обрабатываются так, как это сделал бы экспериментатор: «титр» — это свободный фаг плюс
инфекционные центры, «титр после хлороформа» — свободный фаг плюс зрелые внутриклеточные частицы.

## Модель чашки Петри (модуль 2)

* **Газон.** Бактерии в мягком агаре растут одинаково по всей чашке (питание общее) с временем
  удвоения в агаре 45 мин, пока не кончится питание (по умолчанию газон перестаёт расти через ≈ 6,7 ч,
  плотность 5·10⁹ клеток/мл).
* **Бляшка** — радиальная модель реакции–диффузии (кольца с шагом 14 мкм, 3,5 мм от центра).
  В каждом кольце: чувствительные клетки, заражённые когортами по возрасту развития (та же биология,
  что в колбе: эклипс, урожай, торможение лизиса со срывом и максимальной длительностью, исключение
  суперинфекции, голодание хозяина), свободный фаг с диффузией D_p (неявная схема), оболочки.
* **Разброс размеров.** Каждый посеянный вирус находит бактерию в своё время t₀
  (вероятность не найти — exp(−k∫S dt)); поздняя бляшка растёт в уже густом газоне и вырастает меньше.
  Полностью считаются 5 опорных бляшек по квантилям t₀, остальные получают профиль по интерполяции.
* **Чашка** составляется из бляшек в случайных точках. Перекрывающиеся бляшки перемножают мутность.
  Больше 6000 бляшек на чашку рисуются как равномерное просветление (сплошной лизис).
* **Диаметр бляшки** — по прозрачной зоне (мутность меньше 20 % от газона); ореол — до 90 %.
* **Капля щелчком**: вирусы из капли рассыпаются по пятну радиусом 2,5 мм и начинают свои бляшки
  с момента падения капли; капля в голодный газон даёт крошечные бляшки или не даёт их совсем.
* **Опыты для ученика:** «Бляшки на газоне», «Сколько вирусов в пробирке?» (6 разведений, ручной
  счёт щелчками, расчёт титра по шагам и проверка ответа), «Обычный вирус и мутант»,
  «Почему бляшки перестают расти?» (вторая чашка с выключенной причиной: питание, голод, торможение
  лизиса, жидкий агар), «Капни сам». Колёсико мыши увеличивает чашку до ×40 — видно микроколонии
  газона и мутный край бляшки.
* **Проверки:** диаметр T4 1,7 мм через 16 ч, рост останавливается через 8 ч; r-мутант и T4 без
  торможения лизиса — 2,1 мм с резким краем; наклон титрования −1,01; сетка 256 → 512 колец — 2,6 %.

## Модель микроскопа (модуль 3)

* Клетка — капсула (отрезок с радиусом 0,5 мкм): растёт экспоненциально по Моно, делится при длине
  ≈ 4 мкм (±10 %) с небольшим отклонением угла. Заражённые клетки не растут.
* Механика: позиционная динамика без инерции — перекрывающиеся капсулы раздвигаются поступательно
  и поворотом; соседи ищутся по равномерной сетке. Клетки, вытолкнутые за край поля, уходят из кадра.
* Фаг — непрерывное поле на сетке 1 мкм с диффузией (D_p). За шаг клетки поглощают долю
  1 − exp(−k·φ·dt/H) фага в узле (φ — доля площади узла под клетками); поглощённые фаги
  распределяются по клеткам и разыгрываются как целые события (заражение, повторная адсорбция).
* Биология заражения та же, что в колбе (латентный период с разбросом, эклипс, урожай, торможение
  лизиса, исключение суперинфекции, голодание хозяина). Проверка «Цикл заражения в микроскопе»
  подтверждает согласие с колбой: лизис через ≈ 24 мин, урожай ≈ 145.
* Субстрат — общий для поля запас глюкозы в слое агара под ним; когда он кончается, газон
  перестаёт расти, а фаг в голодных клетках размножается плохо — пятно (бляшка) перестаёт расти.
* Отрисовка, переключатель «Как смотреть»:
  * **Светящиеся метки** (флуоресценция). Чёткий край, мембрана чуть ярче, середина ярче краёв
    (там клетка толще). Цвет показывает состояние клетки, светлые крупинки внутри заражённой
    клетки — собирающиеся вирусы (их число равно накопленному урожаю / 8).
  * Детали клетки: нуклеоид (ДНК) расходится на два перед делением и тает в первые 6 мин
    после заражения (T4 разрушает ДНК хозяина). Мелкие включения в цитоплазме. При делении
    клетка рисуется двумя половинками с сужающимися концами: растёт перегородка и перетяжка.
  * **Свободные вирусы** — светящиеся точки (не больше 1500; если вирусов больше, одна точка
    обозначает несколько). Каждая точка блуждает случайно с коэффициентом диффузии модели D_p.
    Число и расположение точек каждый кадр сверяются с полем фага в модели: где вирус
    поглощён, точка подлетает к ближайшей бактерии и гаснет, а где поле прибавилось, точка появляется.
  * Свободный вирус рядом с колонией живёт в модели всего 1,5–3 с, а на скорости ×60 это доли
    секунды экрана. Поэтому, когда лопается первая или выбранная бактерия, опыт на 6 с замедляется
    до ×1 (переключатель «Замедлять, когда бактерия лопается»).
  * **Обычный микроскоп** (фазовый контраст). Тёмные палочки со светлым ореолом на сером фоне,
    неравномерная подсветка, соринки вне фокуса. Вирусов не видно, заражённая клетка выглядит
    как здоровая, а лопнувшая оставляет светлую пустую оболочку («призрак»).
  * В обоих видах есть перетяжка перед делением, разброс толщины и яркости клеток, шум камеры
    и виньетирование. Всё это только отрисовка, на расчёт модели не влияет.

## Решения, принятые при реализации (стоит согласовать)

* **Исключение суперинфекции.** Включено: фаг, севший на заражённую клетку, теряется.
  Выключено: упрощённая классическая модель, где такая встреча не уменьшает число свободных фагов;
  сигнал для торможения лизиса при этом сохраняется.
* **Адсорбция на устойчивые клетки.** В ТЗ есть расхождение: в разделе «Устойчивость» фаг на них
  не адсорбируется, а в модуле 1 адсорбируется, но не заражает. Сделан параметр α_R
  (по умолчанию 0 % — рецептор утрачен).
* **Латентный период в пресете — 24,5 мин** (среднее время лизиса). Измеренный по ступеньке
  одиночного цикла латентный период (начало подъёма) получается ≈ 22,6 мин.
* **Макс. длительность торможения лизиса — 90 мин.** С 180 мин просветление культуры при MOI 0,1
  наступало через 5 ч, что выходит за критерий 2–4 ч. Значение нужно сверить с литературой
  (Doermann 1948; Abedon 1992).
* **Выход биомассы Y = 10⁹ клеток/мкмоль** взят из ТЗ, но оценка по массе клетки даёт ≈ 3·10⁸.
* **Чашка считается не на GPU-сетке 512 × 512, а радиальной моделью каждой бляшки.** Фронт бляшки
  узкий: фаг проходит до адсорбции λ = √(D/kS) ≈ 5–30 мкм, а ячейка сетки 512 × 512 на чашку 90 мм —
  180 мкм; на такой сетке скорость роста бляшки зависела бы от размера ячейки. Радиальная модель
  с шагом 7–14 мкм сходится (проверка «Сходимость по сетке») и считается на процессоре за 1–3 с
  на 16 ч. Цена — бляшки не влияют друг на друга (не делят питание и фаг).
* **Время удвоения в мягком агаре 45 мин и 10⁷ клеток/мл при посеве** подобраны так, чтобы газон
  перестал расти через 6–7 ч (критерий остановки бляшки 6–10 ч). С удвоением 20 мин, как в колбе,
  газон густеет за 2 ч и бляшки получаются меньше 0,5 мм.
* **r-мутант крупнее дикого типа только в 1,2 раза** (2,1 против 1,7 мм; по площади в 1,4 раза),
  в литературе разница обычно больше. Фронт бляшки в модели «тянется» передним краем, где вирусов мало
  и торможение лизиса не включается, поэтому оно сужает в основном прозрачную зону (мутный ореол
  0,2 мм у дикого типа против 0,04 мм у r). Вероятно, не хватает локальных всплесков концентрации фага
  возле лопнувшей клетки (в непрерывной модели они размазаны по кольцу). Критерий проверки: больше
  не менее чем на 15 % и край резче.
* **В препарате дикого типа есть r-мутанты с долей 10·μ_r** (препарат выращен примерно за 10 циклов).
  r-мутации внутри растущей бляшки (пёстрые бляшки) и колонии устойчивых бактерий внутри бляшек
  на чашке пока не моделируются.
